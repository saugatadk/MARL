# Major Project: Adaptive Traffic Signal Control using Reinforcement Learning

Undergraduate Major Project on Reinforcement Learning for Traffic Signal Optimization, implemented on real-world road networks using **Eclipse SUMO**, **Gymnasium**, and **Stable-Baselines3**.

## Project Overview

This repository houses the simulation models, reinforcement learning environments, baselines, and benchmarking code for traffic signal control, calibrated for **IOE Pashchimanchal Campus (Western Regional Campus - WRC), Lamachaur, Pokhara, Nepal**.

### Repository Structure
- **[`phase1_single_agent/`](phase1_single_agent/):** Single-agent RL traffic signal control on Lamachaur Chowk (OSM network conversion, SUMO simulation, TraCI Gymnasium environment, Fixed-Time & Actuated baselines, DQN & PPO agents, multi-seed evaluation, and live SUMO-GUI replay).
- **[`Papers/`](Papers/):** Literature review papers and project proposal documentation.
- **[`sample/`](sample/):** Directory for experiment samples and exploratory scripts.

For detailed prerequisites, network generation, training commands, evaluation tables, and visual replay instructions, please refer to **[`phase1_single_agent/README.md`](phase1_single_agent/README.md)**.
